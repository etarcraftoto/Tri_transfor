🔷 基本定義

sin θ = 對邊 / 斜邊
cos θ = 鄰邊 / 斜邊
tan θ = 對邊 / 鄰邊 = sin/cos
csc θ = 1 / sin θ
sec θ = 1 / cos θ
cot θ = 1 / tan θ = cos/sin

🔷 畢氏恆等式

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = csc²θ

🔷 負角公式

sin(−θ) = −sin θ（奇函數）
cos(−θ) = cos θ（偶函數）
tan(−θ) = −tan θ（奇函數）

🔷 餘角公式（90°−θ）

sin(90°−θ) = cos θ
cos(90°−θ) = sin θ
tan(90°−θ) = cot θ

🔷 補角公式（180°−θ）

sin(180°−θ) = sin θ
cos(180°−θ) = −cos θ
tan(180°−θ) = −tan θ

🔷 和差角公式

sin(A±B) = sinA cosB ± cosA sinB
cos(A±B) = cosA cosB ∓ sinA sinB
tan(A±B) = (tanA ± tanB) / (1 ∓ tanA tanB)

🔷 二倍角公式

sin 2θ = 2 sin θ cos θ
cos 2θ = cos²θ − sin²θ
          = 2cos²θ − 1
          = 1 − 2sin²θ
tan 2θ = 2tanθ / (1 − tan²θ)

🔷 半角公式

sin²θ = (1 − cos 2θ) / 2
cos²θ = (1 + cos 2θ) / 2
tan(θ/2) = sinθ / (1 + cosθ)
           = (1 − cosθ) / sinθ

💡 將兩個三角函數的乘積轉換為和或差的形式

  • sin A · cos B = ½ [sin(A+B) + sin(A−B)]
    → 一正一餘，取 sin 的和差
  • cos A · sin B = ½ [sin(A+B) − sin(A−B)]
    → 一餘一正，取 sin 的和差（注意符號）
  • cos A · cos B = ½ [cos(A−B) + cos(A+B)]
    → 兩餘相乘，取 cos 的和差
  • sin A · sin B = ½ [cos(A−B) − cos(A+B)]
    → 兩正相乘，取 cos 的差（注意符號相反）
📝 記憶口訣
正餘 → sin和差，餘餘 / 正正 → cos和差
兩正相乘記得 cos 要「差減和」
所有結果都要乘以 ½

💡 將兩個三角函數的和或差轉換為乘積的形式

  • sin A + sin B = 2 sin((A+B)/2) · cos((A−B)/2)
    → sin和 → sin半和 × cos半差
  • sin A − sin B = 2 cos((A+B)/2) · sin((A−B)/2)
    → sin差 → cos半和 × sin半差
  • cos A + cos B = 2 cos((A+B)/2) · cos((A−B)/2)
    → cos和 → 兩個 cos 相乘
  • cos A − cos B = −2 sin((A+B)/2) · sin((A−B)/2)
    → cos差 → 負號 × 兩個 sin 相乘
📝 記憶口訣
結果都是 2 × (半和) × (半差)
sin±sin：一定有 sin×cos（sin和→sin前，sin差→cos前）
cos+cos：cos×cos
cos−cos：負號 + sin×sin
